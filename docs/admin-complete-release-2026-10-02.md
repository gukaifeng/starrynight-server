## 问题与处理

- 历史语音关联数据同时存在字符串发言、结构化发言与空发言。第一次线上声音列表触发兼容错误，已兼容全部三类并加入回归测试；当前声音列表与 WAV 播放返回正常。
- 本机 Python HTTPS 及 Node 独立请求客户端出现传输失败，原生直连 curl 与真实 Chrome 同源请求正常。浏览器验证改用页面 `fetch`，保持原鉴权、证书及 CSRF；没有放宽服务器安全设置来绕过本机问题。
- 在完整备份暂停 AI 时并行验证 AI 只读页面，会遇到服务暂时不可用。线上 UI 验证安排在维护完成之后，任务状态在维护期间仍可查询。
- 完整备份初版把媒体压缩包含在停机期间，实测约 142 秒。改为数据库及独立媒体副本复制完成后恢复 App 服务，再压缩和校验。临时副本不进入恢复清单，复制失败也恢复服务；备份清单记录实际暂停时间，维护页显示阶段。
- 新维护任务使用独立、有限期的 user-systemd 单元并写入私有 JSON 状态。配置应用真实重启管理服务后，任务仍能完成并在网页查询。
- 优化后的线上备份验证客户端中途遇到 `Failed to fetch`，没有重复创建备份或误报任务失败。通过独立 SSH 状态检查确认原任务完成，再重新执行备份完整性校验与公网检查；失败验证日志保留在本机。
