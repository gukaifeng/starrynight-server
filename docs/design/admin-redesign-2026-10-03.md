# 控制台前端重建（2026-10-03）

用户要求清空原控制台前端重新设计，采用现代简约风格，重点解决用户页、角色页的信息格式混乱。此次只修改独立服务端仓库的管理前端，不修改客户端、角色资产、AI 提示词、服务端数据结构或公共 App API。

## 设计与结构

- 配色：浅灰底 `#f6f8fa`、白色面板 `#ffffff`、深灰蓝文字 `#202b3b`、辅助文字 `#64748b`、青绿强调 `#0d807b`、浅青绿选中背景 `#edf8f7`。删除原有深色侧栏、装饰性英文标题和衬线字体。
- 中文使用系统无衬线字体，英文使用 IBM Plex Sans，ID 与原始记录使用 IBM Plex Mono。正文 13–14px，辅助信息 11–12px，模块标题 16px，页面标题 25px；角色、用户采用同一套间距和字号。
- 218px 固定侧栏只放用户、角色、后台数据三个入口和常用工具；其他全部数据从可搜索、可分类的后台目录进入，避免数十个菜单长列表。
- 用户与角色页统一为身份区、资料概览、关联关系、对象归档、AI 运行数据。资料与统计分栏，窄屏自动叠放；用户与角色的关系提供双向跳转。
- 所有管理详情使用同一套右侧抽屉，统一详情、编辑、原始数据和危险操作确认。手机宽度下抽屉铺满可视区域，表格仅在自身容器内横向滚动。

## 信息格式修复

原页面在卡片、裸 JSON、长表格之间切换，未知对象还会被直接序列化塞入表格。新建 `ConsoleUI.tsx` 与 `DataWorkspace.tsx`，重新实现页面和组件，不复用旧 App 或 EntityExplorer 的页面结构和 CSS。

- 默认把对象呈现为字段名称和值，数组按项目展开；深层对象使用可折叠的层级。中文标签覆盖常见账户、角色、目标、设定字段；未知扩展字段完整保留。
- 不把对象直接放进表格；列表显示名称、内容摘要或字段/项目数量，完整内容进入抽屉查看。
- 保留换行、数字 0、布尔否、空值的区别；统一处理 SQLite 秒级时间和 PostgreSQL ISO 时间。
- 完整原始数据通过显式展开或抽屉原始数据页查看，未删字段，也不混入默认资料呈现。
- 账户同步消息与 AI 实际上下文分别统计，不能相加。历史 AI 所有者没有正式账户关联时不伪造用户链接。

## 保留的管理能力

重新实现登录、导航、搜索、游标翻页、用户/角色资料、关系和目标、资源记录查看/创建/编辑、头像上传、管理操作确认、总览、服务日志与可允许的重启操作。继续使用现有 SCS/CSRF 会话、权限、版本冲突检查、重置幂等 ID 和操作审计接口。

资源上传/浏览/预览、声音文件、OSS、会话缓存、备份恢复、运行配置、版本证书、文件、维护任务、3D 预览和完整语音耗时诊断保留已验证的专用业务逻辑，统一接入新页面外壳与设计样式。未扩大接口权限，未引入直接 SQL、任意路径或任意 shell 功能。

删除不再使用的 Fraunces 字体依赖。主入口压缩后约 114 KB gzip；Three.js 预览继续懒加载（大型预览分包约 723 KB，Vite 仍提示分包大小，不是构建错误）。

## 验证方式

- 前端 TypeScript / Vite 构建和 Vitest：新增异构数据格式、秒级/ISO 时间、未知嵌套扩展及文本转义检查，合计 5 项。
- Go race 单元测试、完整构建和独立 PostgreSQL/Redis 集成测试。初次集成命令误用了 `DATABASE_URL`，被专用测试库防护拒绝；改用 `TEST_DATABASE_URL` / `TEST_REDIS_URL` 后通过，没有连接生产数据库。
- `scripts/verify_admin_redesign_browser.mjs` 是新端到端验收入口；原维度验收委托到此入口，其余浏览器脚本适配新的菜单、窗口与字段布局。
- 本地使用先前的隔离测试数据库/Redis与无密钥、禁付费的 AI fixture，非已经退役的 Mac 旧部署。创建/编辑测试仅允许 localhost，生产验收只读。
- 浏览器尺寸：1512×1050、1024×844、390×844。检查身份验证、懒统计、游标分页、搜索、关联跳转、范围记录、设定编辑、资源管理、凭据隐藏、抽屉和无页面横向溢出。
- 画面与接口细节留在忽略目录 `.local/`，不把用户数据、对话、资源图片或管理认证材料提交到公开仓库。

实际部署版本、生产验收结果另记部署文档。

## 已完成的本地验收与问题处理

本地完整端到端验收通过，额外三个浏览器套件也通过：管理读写与确认、41 角色 / 82 张图片解码及大图预览、8 个服务器管理入口与 PCM→WAV 试听。页面未产生 JavaScript 错误，未调用付费 AI。

窄屏补测发现真正的页面横向溢出：表头的屏幕阅读器专用文字采用绝对定位，没有局部定位容器，落在横向滚动表格以外，扩大了文档宽度。给表头建立定位容器后，图片详情与表格均在 390px 内正常显示。统一将模态根节点设为固定视口区域，解决抽屉根节点零尺寸的问题。二次确认关闭后仍保留原资料抽屉，验收按确认窗口名称判断，不再误判原抽屉为未关闭的确认弹窗。

本地专用声音 fixture 使用静音 PCM，仅验证真实接口封装和播放器加载，不模拟声线质量、不消耗百炼额度。测试数据库及 fixture 在验收后停止，未恢复退役 Mac 服务。
