# 角色、设定与独立会话重构实施记录

用户已批准完整实施。本文记录已落地的阶段及实际验证，后续阶段继续更新；整体重构尚未完成，也尚未切换生产默认入口。

## 阶段一：可并行于旧平台的内容与实例基础

- 增加 v2 设定合约：公开资料、结构化场景/目标/语言、稳定 ID 文本块、参数、三组开场、兼容要求、可保留的命名空间扩展。草稿保留 raw_fields 和未完成输入；发布另做完整语义检查。
- JSON Schema 2020-12 使用 jsonschema/v6 6.0.3。规则树仅能引用注册的固定公开字段，服务端生成受控 CEL 表达式，使用 cel.dev/cel-go 0.32.0。未知属性不因 NOT 变为可用；身高只作剧情属性。
- 草稿与冻结源稿采用标准 AES-GCM 信封加密，AAD 绑定 owner/resource/version，部署密钥支持轮换；公共 DTO、保存回执及账户同步事件不复制源稿。
- 草稿强 ETag/CAS、所有权 SQL、幂等保存回执和最多 20 份自动检查点。重复保存回执在版本检查之前识别，跨 API 节点重试不会误报冲突。墓碑不会被旧离线保存复活。
- 冻结修订、校验任务、实际人工公开审查、发布头、收藏、撤下/私有化/撤销分别维护。后来的草稿编辑不改变正在审查的内容；访问变化递增版本/代次，旧校验不能重新公开撤销作品。
- PostgreSQL outbox/job 为任务权威，Asynq 0.26.0 为 Redis 投递执行层。短执行租约、fence、节点退出回收与重投递，队列中只存 job ID；不把作者源稿复制进 Redis 任务。
- 独立 conversation_instances 允许同一人物/设定创建多个平行故事。创建/隐藏/重置幂等；模型资产仍共享。重置清理该实例消息、记忆状态、翻译与候选，不清除其他故事。
- 新迁移 17/18 为增量，旧 user×character 表保持原状。未来作者注销撤销使用、删除私有源稿，保留消费者自己的历史；不可变源稿/发布内容由数据库触发器保护。
- 功能受 SETTING_PLATFORM_ENABLED 保护，启用必须有独立 CONTENT_KEYS_JSON/CONTENT_ACTIVE_KEY。旧 v1 会话、音频、账号及下载尚未切换。

## 验证与问题处理

- 修改前 Go race 单元基线通过；原 Python AI worker：375 passed、4 skipped，全程不调用付费供应商。
- 新单元测试验证密文跨 owner/resource/version 认证、轮换及篡改拒绝；兼容性未知/否定/集合/数值边界与非法字段；不完整草稿、扩展、参数与发布校验。
- 真实隔离 PG/Redis、两个 API 实例验证：账号隔离、失去保存响应后重试、CAS 冲突、弱 ETag 拒绝、检查点恢复、墓碑、公开 DTO 无源稿、冻结后编辑、Asynq outbox 实际执行、公开审查、私有化、平行故事、单实例重置、作者注销历史保留。
- 本机已有 starry_test 停在不一致的旧迁移状态（版本 11 已登记，但注册序列缺失）。没有修写历史迁移或触碰生产，另建专用 *_test 库从零验证新旧迁移。迁移开发时一次触发器调整仅作用于这个本轮创建的隔离测试库；生产上线仍需从冻结的正式迁移执行。
- Huma 的跨包同名 Goals schema 发生启动冲突，内容类型改用 Setting 前缀，OpenAPI 生成已通过。
- pgx exec 模式不能推断自定义 Go 结构的参数 OID；显式编码成 json.RawMessage，保持 PgBouncer transaction pooling 兼容。对外错误仍不输出参数、SQL 或源稿。
- 公开发布原不可变触发器也阻止账号删除时 submission_id FK 置空；保护限定于不可变内容列，审查来源保留于 review_receipt，账号删除场景已加入回归。
- Go make test/build、完整 make integration 已执行；后续修改后继续执行必要回归。具体阶段结束结果以对应日志及本记录后续更新为准。
